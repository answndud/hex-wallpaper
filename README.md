# Hex Wallpaper

HEX 색상 코드로 단색 또는 그라데이션 PNG 배경화면을 만드는 정적 웹 도구입니다.

## 기능

- HEX 코드 직접 입력 또는 컬러 피커 선택
- 단색, 2색 그라데이션, 3색 그라데이션 모드
- 그라데이션 각도 조절
- 1 MB, 2 MB, 3 MB PNG 다운로드
- 1920 x 1080, 2560 x 1440, 3840 x 2160, 1080 x 1920, 1600 x 1600 해상도 선택
- 새로고침 시 입력 상태 초기화

## 사용 방법

1. `index.html`을 브라우저에서 엽니다.
2. 모드와 HEX 코드를 입력합니다.
3. 파일 크기와 해상도를 선택합니다.
4. 다운로드 버튼으로 PNG 파일을 저장합니다.

## GitHub Pages

정적 파일 하나로 동작하므로 GitHub Pages에서 별도 빌드 없이 배포할 수 있습니다.

예상 URL:

```text
https://USERNAME.github.io/hex-wallpaper/
```

## 구현 메모

브라우저 Canvas API로 PNG를 생성하고, 선택한 파일 크기보다 PNG가 작을 때 PNG 보조 청크를 추가해 목표 용량에 맞춥니다. 모든 처리는 클라이언트에서 실행됩니다.
